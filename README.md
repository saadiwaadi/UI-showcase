# UI Showcase

A collection of premium, interactive, and fully responsive single-file front-end UI mockups. Each mockup is self-contained and designed with rich aesthetics, modern typography, custom color palettes, and smooth animations.

## Showcase Mockups

Here is a list of the UI designs included in this repository:

1. **Dental Clinic Booking System** (`Dental clinic booking system.html`)
   - An elegant clinical dashboard and booking management app.
   - Features patient profiles, visit logging, intake forms, and clinical history views.

2. **Sales CRM Mockup** (`SALES crm-mockup.html`)
   - A highly functional sales CRM interface featuring pipeline management, dynamic contact workflows, and interactive status boards.

3. **BeeHome** (`beehome.html`)
   - A modern and vibrant smart-home control panel or landing page.

4. **Qatar Realty Dashboard** (`qatar-realty-dashboard.html`)
   - A premium, data-dense dashboard for tracking and analyzing real estate listings, sales performance, and market statistics.

5. **Roost Hotel App Mockup** (`roost-hotel-app-mockup.html`)
   - A sleek, high-end hotel booking and reservation application featuring smooth micro-interactions.

6. **Siyaahi Landing Mockup** (`siyaahi_landing_mockup.html`)
   - A beautifully styled creative landing page focusing on premium design, elegant typography, and rich visual layout.

## Features
- **Zero-Dependency**: Every mockup is single-file HTML, making them highly portable and offline-capable.
- **Modern Typography**: Custom Google Fonts integrated for polished, contemporary styling.
- **Responsive Layouts**: Designed to adapt seamlessly across desktop, tablet, and mobile screens.
